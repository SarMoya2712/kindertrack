# Группы и Excel — 14 октября 2026

## Готово

- Группы связаны с детьми через существующий обязательный `children.group_id`. Форма создания/редактирования сохраняет выбранную активную группу; прежнее назначение в неактивную группу можно сохранить без нового назначения другим детям.
- Список групп показывает имя, описание, статус, общее/активное число детей, присутствующих/отсутствующих сегодня, посещения и начисления за выбранный период.
- Карточка группы показывает показатели и процент посещаемости, детей с фото/ID/ФИО/тарифом/числом посещений/статусом и ссылками просмотра/редактирования. На телефоне — карточки, на большом экране — таблица.
- Поиск по ФИО/ID, фильтры «все / активные / неактивные / присутствуют / отсутствуют сегодня» и пагинация. Выбранный поиск/статус сохраняется при смене периода.
- Статистика поддерживает конкретную группу или все группы. Дневные диаграммы, итоговые показатели и диагностика распознаваний без посещения используют выбранную группу.
- Excel использует те же даты/группу, только PostgreSQL и реальные суммы посещений.
- Все новые подписи, включая листы Excel, доступны на RU / UZ / ЎЗ.

## База данных и маршруты

**Новых таблиц, колонок и миграций нет.** Используются текущие внешние ключи и индексы `children.group_id`, `attendance.child_id`, `attendance.attendance_date`. Данные детей не дублируются в группах. История посещений не изменяется.

Новые маршруты (оба требуют Admin):

- `GET /groups/<group_id>` — подробная страница группы.
- `GET /statistics/export.xlsx` — скачивание Excel.

Обновлены `GET /groups` и `GET /statistics`. Экспорт понимает `period`, `start`, `end`, `group_id`. Кнопка на странице передаёт явно показанные даты через `period=custom`, чтобы переход через полночь не изменил диапазон. `group_id` отсутствует/пуст для всех групп. Некорректная или несуществующая группа возвращает 404 и не расширяет выгрузку до всех детей.

## Как считаются показатели

Источник состава — только текущий `children.group_id`.

- Всего: `COUNT(children.id)` в группе.
- Активных: тот же подсчёт с `children.status = 'active'`.
- Сегодня пришли: число детей с `EXISTS (attendance WHERE child_id = children.id AND attendance_date = today)`.
- Отсутствуют: всего минус присутствующие; включает неактивных детей. Это явно объяснено в интерфейсе.
- Процент: `present / total * 100`, один десятичный знак; пустая группа — 0%.
- Посещения периода: количество записей `attendance` с датой между началом и концом **включительно** и ребёнком в текущей группе.
- Начислено: `SUM(attendance.amount)` по тем же условиям, Decimal/NUMERIC.
- Уникальные присутствовавшие: `COUNT(DISTINCT attendance.child_id)` за период.
- Среднее: количество посещений / все календарные дни периода, включая дни без посещений.

Состав и посещения предварительно агрегируются отдельно, затем присоединяются к `groups`, чтобы несколько посещений одного ребёнка не умножали численность. Пустые и неактивные группы также доступны в отчётах. Сегодня и время в Excel — `Asia/Tashkent`; дата посещения фильтруется как DATE, без хрупких UTC-границ.

При переводе ребёнка его посещения учитываются в отчёте **новой текущей группы**, включая прошлые даты. Это соответствует запросу фильтровать по детям, принадлежащим группе; история состава групп отдельно не хранится. Сами строки посещений, снимки тарифов и суммы остаются прежними. Неизвестным лицам группа не приписывается.

## Excel

Зависимость: `openpyxl>=3.1.5,<4`; установлена версия 3.1.5.

Создаются четыре листа (названия по умолчанию):

1. **Общая статистика** — период, группа, всего детей, уникальные присутствовавшие, посещения, начислено, среднее и пояснение текущего состава групп.
2. **Посещения** — №, дата, время, ID, ФИО, группа, тариф на момент посещения, начислено. Одна строка на посещение; обе исторические денежные колонки берутся из `attendance.amount`.
3. **По детям** — ID, ФИО, группа, количество посещений и начисление за период, текущий тариф, статус. Включены дети без посещений.
4. **По группам** — группа, всего детей, уникальные присутствовавшие за период, посещения, начислено. При выборе одной группы — только её строка.

Необязательный лист неизвестных лиц не добавлен. Фотографии и контакты родителей не экспортируются.

Оформление: тёплая бежевая палитра, жирная строка заголовков, перенос текста, ширины по длине имён/названий с ограничением для читаемости, закрепление A2, автофильтры таблиц, денежный формат `#,##0.00`, даты `dd.mm.yyyy`, время `hh:mm:ss`.

Выгрузка выполняется в отдельной read-only транзакции PostgreSQL с `REPEATABLE READ`, поэтому все листы отражают один снимок, даже если во время генерации камера добавляет посещения. Суммы могут отличаться от ранее открытой страницы, если данные изменились **до** начала выгрузки; это реальные новые данные.

Потоковый режим openpyxl и чтение посещений партиями по 1000 ограничивают расход памяти на длинных периодах. Итоговый ZIP/XLSX формируется в BytesIO, без перезаписи файлов проекта; временные XML-файлы библиотеки удаляются при успешном сохранении. Имя: `statistics[_group_ID]_YYYY-MM-DD_YYYY-MM-DD.xlsx`.

Все строки экспортируются как текст, в том числе начинающиеся с `=`, что предотвращает выполнение внедрённых Excel-формул. Произвольные пути не принимаются, имя формируется из проверенных дат/числового ID. Ответ приватный, `no-store`, только для авторизованного Admin.
